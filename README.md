# Nudity Guard — إضافة Stremio

تعرض تحذير "الجنس والعري" (من IMDb Parents Guide) كأول عنصر في قائمة المصادر
لأي فيلم أو مسلسل، قبل أن تختار مصدر التشغيل.

## الطريقة الموصى بها: استضافة مرة واحدة (تعمل على التلفاز والحاسوب)
1. أنشئ مستودعاً على GitHub وارفع الملفات: server.js و package.json و Dockerfile.
2. في موقع استضافة مثل Render أو Koyeb أو Railway: New → Web Service → اختر المستودع.
   - Start command: `node server.js` (أو دعه يستخدم Dockerfile).
   - لا تحتاج متغيرات بيئة، والمنفذ يُؤخذ تلقائياً من PORT.
3. ستحصل على رابط مثل `https://nudity-guard.onrender.com`.
4. ثبّت الإضافة بالرابط: `https://.../manifest.json`
   - الحاسوب: Stremio → Addons → الصق الرابط في خانة البحث عن الإضافات → Install.
   - التلفاز: أسهل طريقة تثبيتها من الحاسوب بنفس حساب Stremio، فتظهر على التلفاز تلقائياً.
5. رتّب الإضافات بحيث تكون Nudity Guard الأولى لتظهر أعلى القائمة.

ملاحظة: الخطط المجانية تنام بعد فترة خمول، فأول طلب بعد الخمول قد يتأخر أو يفشل مرة،
وتحدّث بعدها بسرعة.

## بديل: تشغيل على حاسوبك فقط
```
node server.js
```
ثم `http://127.0.0.1:7000/manifest.json` على تطبيق الحاسوب فقط. التلفاز لا يصل إلى هذا العنوان.
